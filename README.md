# 🧮 DeskCalc Standard Edition (v3.0.0)

A lightweight, distraction-free desktop calculator crafted with Python and CustomTkinter. 

Designed for quick office calculations, tax estimates, and daily arithmetic.

---

## 📦 Features

- **Clean Aesthetic:** Modern dark-mode interface with zero visual clutter.
- **Pure Arithmetic:** Standard operations: addition, subtraction, multiplication, and division.
- **Zero Bloat:** Minimal memory footprint, launches instantly on Windows and Linux.
- **Keyboard Friendly:** Full support for Numpad, `Enter` to evaluate, and `Backspace`.

---

## 🚀 Quick Start

Ensure you have Python 3.8+ installed:

```bash
pip install customtkinter
python3 gui_calculator.py
