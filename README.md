# ⚡ Hardcore Python CLI Calculator

Мощный интерпретатор математических выражений на базе Abstract Syntax Tree (AST).

## 🚀 Фичи:
- **Безопасность:** Никакого опасного `eval()`, разбор выражений через AST-парсер.
- **Поддержка переменных:** `radius = 10`, `area = pi * radius^2`.
- **Встроенные функции:** `sin`, `cos`, `tan`, `sqrt`, `ln`, `log`, `fact` (факториал), `abs`, `round`.
- **Константы:** `pi`, `e`, `phi`, `tau`.
- **Память:** Последний результат сохраняется в `ans`.
- **Команды оболочки:** `vars`, `history`, `clear`.

## 📦 Запуск:
Требуется Python 3.8+ (без сторонних библиотек):
```bash
python calculator.py
